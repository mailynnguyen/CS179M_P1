# AI Senior Project 1

A program to find the fastest route for a drone to fly through points (and apply paste) and back to original point.
Uses a greedy nearest neighbor algorithm - finds the neareset point of all points and travels to there and so on.
After finding the first solution (usually optimal), tries to find better solutions by swapping two random points in best solution.

After the user hits 'Enter' to stop program, solution is written to a text file and a visual of the solution is created.
